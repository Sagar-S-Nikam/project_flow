PART 1 — Learn the Basics First

All technologies used in this project explained in simple words before touching any code

What is a Web Application?

A web application has 3 parts that work together:

🖥️

Frontend

What the user SEES in the browser. In our project: Angular running on port 4200.

⚙️

Backend

The brain behind the scenes. Handles logic, processes data. In our project: Spring Boot on port 8081.

🗄️

Database

Stores everything permanently. Even after server restart, data is safe. In our project: MySQL on port 3306.

Real World Analogy

Think of a restaurant. Frontend = the menu you see. Backend = the kitchen that cooks. Database = the storage room where food is kept.

2

What is Java & Spring Boot?

☕ Java

Java is a programming language. We use it to write the backend logic — like registering users, checking passwords, generating sensor data, saving to database.

🚀 Spring Boot

Spring Boot is a framework built on top of Java. A framework is like a ready-made toolkit. Instead of building everything from scratch, Spring Boot gives us pre-built tools for making APIs, connecting to databases, handling security, etc. It also has a built-in web server (Tomcat) so you don't need to install one separately.

Analogy

Java = the language you speak. Spring Boot = a pre-built house where you just decorate the rooms instead of building walls from scratch.

📌 Important Annotations (Special Labels)

@SpringBootApplication — Marks the main class. Starts the whole application.
@RestController — This class handles HTTP requests (like GET, POST).
@Service — This class contains business logic.
@Repository — This class talks to the database.
@Entity — This Java class maps to a database table.
@Autowired / @Bean — Spring automatically creates and provides objects (no need to write "new ClassName()" manually).

What is Angular & TypeScript?

📐 TypeScript

TypeScript is like JavaScript but with extra rules. It helps catch mistakes before the code runs. For example, it will warn you if you pass a number where a text is expected.

🅰️ Angular

Angular is a frontend framework (made by Google) for building websites. It divides the website into Components — each component is one piece of the page (like the login form, the dashboard, the chart). Each component has 3 files: .ts (logic), .html (layout), .css (style).

Analogy

Angular is like building with LEGO blocks. Each block (component) is independent. You assemble them to make the full website.

🧩

Component (.ts + .html + .css)

One screen/page of the app. E.g. Login, Dashboard, Home are all separate components.

🔧

Service (.ts)

Makes HTTP calls to the backend. Auth service handles login/register. Simulator service handles pipes and sensor data.

🛣️

Routes

Maps URLs to components. /login → Login component. /dashboard → Dashboard component.

What is MySQL & Database?

🗄️ Database

A database is like a very organized digital filing cabinet. It stores data in tables (like Excel sheets). Each table has rows (records) and columns (fields).

🐬 MySQL

MySQL is a popular database software. It stores data permanently on your hard disk. Even if the computer restarts, all the data is still there.

Analogy

MySQL = a collection of Excel sheets saved permanently on your computer. Each sheet = one table (users_data, pipes, waterpara).

🔑 Key Terms

Primary Key (PK) — Unique ID for each row. Like a roll number.
Foreign Key (FK) — Links two tables. pipe's user_id points to users_data's id.
@Entity — Java class automatically becomes a table in MySQL when app starts.

HTTP is the language browsers use to talk to servers. When you open a website, your browser sends an HTTP request and the server sends back an HTTP response.

📡 REST API

REST API is a set of rules for how the frontend and backend talk to each other. The frontend sends a request to a URL and the backend responds with data (usually in JSON format).

What is JPA / Hibernate?

🔄 JPA (Java Persistence API) + Hibernate

Normally, to save data to MySQL you write SQL: INSERT INTO users_data (username, email) VALUES ('sagar', 'sagar@x.com'). With JPA + Hibernate, you just call userRepository.save(user) in Java and it automatically writes the SQL for you!

✨ Spring Data JPA — Magic Method Names

You write a method name in a special way and Spring generates the SQL automatically:

No SQL needed — method name IS the query
// You write this method name in your Repository interface:
List<Pipes> findByUserId(Long userId);

// Spring automatically generates this SQL:
// SELECT * FROM pipes WHERE user_id = ?

// Another example:
Optional<Waterpara> findFirstByPipeIdOrderByTimestampDesc(Long pipeId);
// SELECT * FROM waterpara WHERE pipe_id=? ORDER BY timestamp DESC LIMIT 1
Analogy

JPA = a translator. You speak Java, MySQL speaks SQL. JPA translates Java into SQL automatically so you don't have to learn SQL.

8

What is Spring Security & BCrypt?

🛡️ Spring Security

Spring Security protects your application. It checks every incoming HTTP request: "Is this user allowed to access this URL?" If not logged in, it blocks the request.

🔐 BCrypt (Password Hashing)

BCrypt converts a plain password into an unreadable scrambled string called a hash. This hash cannot be converted back to the original password. Even if someone steals your database, they cannot read the passwords.

BCrypt example
// Original password typed by user:
"mypassword123"

// After BCrypt hashing (what gets stored in MySQL):
"$2a$10$N9qo8uLOickgx2ZMRZoMyeIjZAgcfl7p92ldGxad68LJZdL17lhWy"

// BCrypt does NOT reverse this — it only COMPARES
// When user logs in: BCrypt checks if "mypassword123" matches the hash
passwordEncoder.matches("mypassword123", storedHash); // returns true
Analogy

BCrypt = a one-way shredder. You can shred paper (hash password) but you cannot un-shred it. You only check if two documents shred the same way.

What is Session-Based Authentication?

🎫 Session

When you login, the server creates a "session" — a unique ticket proving you are logged in. This ticket (SESSIONID) is stored in MySQL and also sent to your browser as a Cookie. Every time your browser makes a request, it automatically sends this cookie. The server checks the cookie and knows who you are.

1
Login successfulServer creates SESSIONID → stores in MySQL spring_session table → sends as cookie to browser
2
Next request from browserBrowser automatically sends SESSIONID cookie with every request
3
Server checks the cookieLooks up SESSIONID in MySQL → finds the user → allows the request
4
Session expires after 30 minutesSESSIONID deleted from MySQL → user must login again
Analogy

Session = a wristband at a theme park. You pay once (login), get a wristband (SESSIONID). At every ride (request), staff checks the wristband. After park closes (30 min), wristband is invalid.

10

What is @Async & Background Thread?

🧵 Thread

Normally, Java runs code one line at a time — like one worker doing tasks one by one. A Thread is like hiring a second worker who can do a different task at the same time in parallel.

⚡ @Async

@Async tells Spring: "Run this method in a background thread — don't wait for it to finish." Our sensor simulator runs in a background thread every 10 seconds forever. Without @Async, the server would be stuck in the while loop and could never respond to any other requests.

Analogy

@Async = a kitchen timer running in the background. While the timer counts down (sensor generates data), you (the server) can keep taking new orders (handle other requests).

11

What is CORS?

🌐 CORS (Cross-Origin Resource Sharing)

CORS is a browser security rule. It says: "You can only talk to the same server you came from." Angular runs on port 4200 and Spring Boot on port 8081 — different ports = different origins. Without CORS config, the browser would BLOCK Angular from talking to Spring Boot.

✅ Solution

We configure Spring Boot to say: "I allow requests from http://localhost:4200 — let them through." This is done in SpringSecurity.java.

Analogy

CORS = a security guard at a building. By default he blocks outsiders. CORS config = telling the guard "let people from building 4200 in."

12

What is AuthGuard & HTTP Interceptor?

🛡️

AuthGuard

Protects pages in Angular. Before loading /home or /dashboard, it checks with the backend "is this user still logged in?" If yes → show page. If no → send to login page. Like a door bouncer.

🔗

HTTP Interceptor

Intercepts every HTTP request Angular makes and automatically adds withCredentials: true. This forces the browser to send the SESSIONID cookie. Without this, backend rejects every request as "not logged in".

13

What is Chart.js?

📊 Chart.js

Chart.js is a JavaScript library for drawing beautiful charts (line, bar, pie, etc.) in the browser. In our project, we use it to draw a live line chart showing pH, Turbidity, and TDS values over time. We add new data points to the chart every 3 seconds and it updates automatically.

Analogy

Chart.js = a digital graph paper. You give it numbers, it draws the graph for you automatically.

The complete simulation loop — simplified
@Async  // Run in background thread
public void start(Long userId) {
    userSimulations.put(userId, true); // Mark as running

    while (userSimulations.get(userId)) { // Loop until Stop is clicked
        List<Pipes> pipes = pipeRepository.findByUserId(userId);
        for (Pipes pipe : pipes) {
            double ph   = 6.0 + Math.random() * 3.0;  // 6.0 – 9.0
            double turb = Math.random() * 7.0;          // 0   – 7.0
            double tds  = 150 + Math.random() * 500;  // 150 – 650

            boolean safe = (ph>=6.5 && ph<=8.5) && turb<=5 && tds<=500;
            data.setStatus(safe ? "SAFE" : "DANGER");
            waterRepository.saveAndFlush(data); // Save to MySQL
        }
        Thread.sleep(10000); // Wait 10 seconds
    }
}

public void stop(Long userId) {
    userSimulations.put(userId, false); // While loop exits
}

Top 8 Questions They May Ask

Q: What does @SpringBootApplication do?
It is placed on the main class (MainApp.java). It combines 3 annotations: @Configuration (app setup), @EnableAutoConfiguration (auto-configure Spring), @ComponentScan (find all controllers/services). Running this class starts the embedded Tomcat server on port 8081.
Q: What is a DTO and why do you use it?
DTO = Data Transfer Object. It is a simple class used to receive data from the frontend. For example, UserDataDTO has only username, email, password — it does not expose all fields of the UsersData entity. It keeps the API clean and secure.
Q: Why use BCrypt for passwords?
BCrypt converts plain passwords into irreversible hashes. Even if someone steals the database, they cannot reverse the hash to get original passwords. BCrypt also adds a random "salt" so the same password gives a different hash each time, preventing rainbow table attacks.
Q: What is @Async and why is it needed in the simulator?
@Async makes a method run in a separate background thread. The simulator has a while loop running forever (every 10 seconds). Without @Async, the POST /start request would never respond — the server would be stuck in the loop forever. With @Async, the loop runs in background and the API responds immediately.
Q: Why is the session stored in MySQL instead of server memory?
If sessions are stored in server memory and the server restarts, all users are logged out. Storing sessions in MySQL (spring_session table) means sessions survive restarts. Configured via spring.session.store-type=jdbc in Application.properties.
Q: How does Spring Data JPA work without writing SQL?
Spring Data JPA reads the method name and generates SQL at runtime. Example: findFirstByPipeIdOrderByTimestampDesc → "SELECT * FROM waterpara WHERE pipe_id=? ORDER BY timestamp DESC LIMIT 1". The keywords (findBy, First, OrderBy, Desc) are parsed into SQL automatically.
Q: What does the Session Interceptor do?
Angular does not send cookies by default due to browser security. The HTTP Interceptor clones every outgoing request and adds withCredentials:true, which tells the browser to send the SESSIONID cookie automatically with every request. Without this, every backend call is rejected as unauthenticated.
Q: Why does the chart have two Y-axes?
pH ranges from 6–9 and Turbidity from 0–7 (small values). TDS ranges from 150–650 (large values). If we used one Y-axis scaled to 650, pH and Turbidity lines would appear flat at the bottom. Dual Y-axis: left axis (0–14) for pH and Turbidity, right axis (0–700) for TDS — all 3 lines visible clearly.
